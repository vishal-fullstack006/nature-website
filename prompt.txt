### Visual Requirements

Make the website visually rich but **not over-designed**.

Use:

* Realistic book/library imagery
* Strong editorial typography
* Large but controlled headings
* Asymmetrical layouts where appropriate
* Thin borders
* Subtle shadows
* Book-cover layouts
* Shelf-inspired elements
* Reading-room sections
* Proper whitespace
* Elegant buttons
* Small labels and metadata
* Subtle hover animations
* Smooth scrolling
* Responsive CSS Grid and Flexbox

Avoid:

* Excessive glassmorphism
* Neon colors
* Cyberpunk design
* Futuristic UI
* Excessive gradients
* Glowing borders
* Floating 3D objects
* Artificial blobs
* Excessive animations
* Excessive pill-shaped elements
* Generic dashboard cards
* Startup/SaaS design
* Overly rounded containers

### Technical Requirements

Use only:

* HTML5
* CSS3
* CSS Variables
* Flexbox
* CSS Grid
* Media Queries
* Google Fonts

Do NOT use:

* JavaScript
* React
* Bootstrap
* Tailwind CSS
* jQuery
* External UI frameworks

Make the website fully responsive for **desktop, tablet and mobile**.

Use semantic HTML, accessible contrast, meaningful image alt text, clean class names and well-organized CSS.

**Most important:** The final website should feel like a real library created by a thoughtful web designer/student, with authentic library details and a calm academic atmosphere. It should **not look like a generic AI-generated template**. Preserve the Lumina Library identity and improve the existing files rather than replacing the project with an unrelated design.
